ABOUT

WD is building the infrastructure behind the AI-driven data economy. As AI
scales, so does data. Every interaction, every model, every system generates
data that must be stored, managed, and made accessible over time.

They combine deep engineering expertise with global-scale manufacturing to
deliver storage systems powering hyperscale data centers, cloud platforms, and
enterprise infrastructure worldwide.

THE FIVE TRACKS
--------------------------------------------------------------------------------

*** FIRMWARE ENGINEERING INTERN  <-- TARGET TRACK ***
"Write the code that brings hardware to life."
Develop the low-level software that allows hardware devices to function.
Working at the intersection of hardware and software, building reliable,
high-performance embedded systems.
  - Design, develop, test, and debug embedded firmware.
  - Write software using C, C++, assembly, and other low-level languages.
  - Collaborate with hardware engineers to integrate software with electronic
    systems.
  - Troubleshoot firmware and hardware interactions to improve performance and
    reliability.
  - Support new product development from concept through production.

SYSTEMS DESIGN & INTEGRATION INTERN   <-- strong second choice
"Bring complex systems together."
Ensure hardware and software work together seamlessly.
  - Define system requirements and technical specifications.
  - Evaluate hardware and software compatibility.
  - Coordinate integration of multiple subsystems into complete products.
  - Identify, troubleshoot, and resolve system-level issues.
  - Recommend improvements to performance, reliability, and scalability.

SYSTEM TOOLS SOFTWARE INTERN
"Build the software behind the technology."
  - Design and develop system software, utilities, and engineering tools.
  - Build or enhance operating systems, compilers, networking tools, databases,
    Internet-based applications.
  - Troubleshoot, debug, and optimize software performance.
  - Collaborate with hardware and software engineers on integration.
  - Influence hardware design by developing software that works efficiently with
    new technologies.

APPLICATIONS SOFTWARE INTERN
"Create software that helps teams work smarter."
  - Design, develop, maintain commercial and internal software applications.
  - Write clean, efficient, maintainable code using modern languages.
  - Test, debug, improve application performance.
  - Collaborate to build new features and solve technical problems.
  - Create documentation supporting deployment and maintenance.

DATA ANALYTICS INTERN
"Turn data into insights that drive better decisions."
  - Design and develop data pipelines, databases, and data warehouses.
  - Build software and automation for collecting, processing, analyzing data.
  - Create dashboards, reports, and visualizations.
  - Partner with stakeholders to translate business needs into technical
    solutions.
  - Analyze data to identify trends, improve processes, solve problems.
